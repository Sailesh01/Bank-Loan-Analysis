# 💰 Bank Loan Analysis Dashboard

Interactive dashboards built with Excel, Power BI, Tableau, and MsSQL to analyze loan performance and assess financial risk.

The project focuses on tracking KPIs like funded amounts, repayments, interest rates, and DTI ratios. It highlights trends across time, loan status, borrower demographics, and regional performance.

📊 Dashboard Sections:
- **Summary View**: Loan KPIs, MoM/MTD trends, good vs. bad loan metrics
- **Overview**: Lending trends by state, employment, loan purpose, and home ownership
- **Details View**: Interactive filtering and data export

🔍 Tools used: Excel, Power BI, Tableau, MsSQL
